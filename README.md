## Управление

A,D - бег влево/вправо(после разговора с мышкой - усиленные прыжки от стены)
проблел - прыжок(при зажатии space прыжок немного усиливается)
Shift - рывок
ЛКМ - удар
ПКМ - отхил
E - начать диалог с NPC
T - сохраниться(рекомендовано перед боссом)
W - Супер рывок

## Цель проекта

Создание компьютерной игры в жанре метроидвания, с мрачной стилистикой.

## Используемые технологии

Для разработки игры мы используем [Unity](https://unity.com/ru) и [C#](https://learn.microsoft.com/ru-ru/dotnet/csharp/).

Создание компьютерной игры в жанре метроидвания, с мрачной стилистикой.

## Управление

* **A, D** — бег влево/вправо
* **Space** — прыжок (при зажатии усиливается)
* **Shift** — рывок
* **ЛКМ** — удар
* **ПКМ** — отхил
* **E** — начать диалог с NPC
* **T** — сохраниться
* **W** — Супер рывок
* **PS**: На второй локации, после подъема по лестнице ломаемые блоки
